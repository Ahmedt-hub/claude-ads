# Store Profile (fixed facts, never ask about them)

Edit this file when the store setup changes. Everything here applies to every product.

## Market
- Country: **Algeria**
- Language: natural Algerian darja, clear for all regions. Same register from top
  to bottom; never mix formal Arabic and darja in one sentence.
- Use masculine imperative for unisex products (اطلب، شوف) and feminine for
  women's products (اطلبي، شوفي).
- Currency: `دج` written after the number (`1900 دج`).

## Platform: Foorweb landing page
- Page = ONE long image, then the order form. No other images, no product gallery.
- A sticky order bar ("تقديم الطلب" + price + offer name) is always visible at the
  bottom while scrolling. So: **no CTA button at the top of the image**.
- The form is directly BELOW the image. The last section ends with an arrow and a
  line pushing down to the form, e.g. `⬇️ املأ الاستمارة تحت واختار عرضك`.
- Offers (quantity deals, bundles) and upsells exist ONLY inside the order form.
  The image announces them with the SAME names and prices, and plants the upsell idea.

## Payment
- Cash on delivery is the default in Algeria and everyone knows it.
  **Never mention it** (no "الدفع عند الاستلام" anywhere, including the CTA).

## Trust (real differentiators, use them)
- Open the parcel before paying: `📦 حلّ الكولي وشوف سلعتك قبل ما تخلص`
- 36-hour money-back guarantee: `🔄 ضمان 36 ساعة: إذا ما عجبكش، نردولك دراهمك`
- Return shipping cost: not confirmed. Do NOT write "الإرجاع علينا".

Placement:
1. First screen: the parcel line under the mini social proof.
2. Objections section: answer "واش يجي كيما في التصويرة؟" with the parcel line.
3. Near the end, before the arrow to the form: both lines together.

## Measuring (for notes and advice only)
- Judge a page by **cost per delivered order**, not by number of orders.
  Watch confirmation rate, delivery rate and returns.
- To test a new headline or hero: duplicate the product page (new link) with the
  new image and run it in a new ad set. Never edit a page that is receiving ad traffic.
- Upsell also happens on the confirmation call: suggest a line for the agent when useful.
